# Classroom Holiday Frame & Radio

Roku channel package with 30 Full HD (1920x1080) winter wonderland & holiday photos and 100 live radio stations.

## Download Zip
- [classroom-holiday-frame.zip](https://github.com/breathofchill/family-frame-and-radio/raw/main/classroom/classroom-holiday-frame.zip)

## Install on Roku TV (Developer Mode)
1. Download `classroom-holiday-frame.zip` above.
2. Open your Roku TV's IP address in a web browser (for example `http://192.168.4.26`).
3. Log in with your Roku developer username (`rokudev`) and password, select `classroom-holiday-frame.zip`, and click **Install**.
